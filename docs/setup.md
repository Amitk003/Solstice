# Setup

## Requirements

- Node.js 20 or newer
- A browser with WebGPU support (recent Chrome, Edge, or Safari)
- Git

## Steps

1. Clone the repository.
2. Install dependencies.

   npm install

3. Start the dev server.

   npm run dev

4. Open the URL printed in the terminal.

## Useful commands

- npm run typecheck : run TypeScript checks
- npm run lint : run ESLint
- npm run build : create a production build
- npm run preview : preview the production build

## Notes

- WebGPU must be enabled in your browser.
- If you see a "not supported" message, update your browser.
- The memory folder is local only and is not part of the repo push.
